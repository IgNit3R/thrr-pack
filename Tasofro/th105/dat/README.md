- **工具**:thtk v12 `thdat.exe -x 105 <档案>`(版本 105 在官方支持表内,见 `thdat --help`)。

- **工作目录纪律**:thdat 输出跟随当前工作目录,全部固定为 `release\tf\th105\dat\<档案名>\` 后执行;
  源目录 `tf\th105\` 零写入(3 个源档案 SHA256 与 `_baseline.tsv` 全符)。
- **事故记录**:首次试运行因目标目录未预建,产物曾落入工作区根目录,已即时迁移归位并复核根目录无残留
  (见 `_progress\t27.md` 事故与处置节)。

## 已知限制(不属本任务范围,供终版报告引用)

- `.cv2`/`.cv3` 为 Tasofro SWR 引擎私有容器(非 thtk thanm 可读的 anm;社区工具见
  [andry-dev/th123toolkit](https://github.com/andry-dev/th123toolkit) 的 th10.5_SE 等),本任务仅原样落盘,不做引擎级解码;
- 本作是**中文汉化版**(目录含 Omake(汉化版).txt),档案内可见中文文件名(如 `天气解释.txt`),
  与日文原版条目命名可能有差异;
- 档案尺寸接近未压缩:th105a 解出 975.3 MB ≈ 源 975.9 MB,判为存储式打包为主。

## 文件名编码说明(【t71】已修正)

th105 档案条目名是**混合编码**:th105a 的 137 个日文条目名为 **SJIS(CP932)**(角色 pose 名、のコピー、全角 ｂ 等),
th105c 的 `天气解释.txt` 为汉化组新增 **GBK 中文名**。thtk thdat 将原始字节直写文件名,在本机 GBK 代码页下
SJIS 名会被误读为 GBK 乱码。t71 已按「SJIS 可解即 SJIS,否则 GBK」规则将 137 个文件改回正确名
(修复脚本:`release\_progress\t71_fix_names.py`),并全量复核 12,697 条目名/大小 0 缺失。
