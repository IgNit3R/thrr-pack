# pushfiles 拆包作业 — 工具登记表

> 生成日期: 2026-08-27(更新: th18+ 官方工具 + tf 侧实测, pushfiles 28 作作业完成)
> 用途: pushfiles 重新拆包/转换作业的工具清单, 含自构建/自编代码
> 红线: 源目录(tsa/tf/tools)只读; 工具沙箱运行; 游戏 exe 从不执行

## 〇、运行注意(th18+ 官方工具实测结论)

- **thtk master 工具为 cygwin 程序**(依赖 `cygthtk-1.dll`,位于同目录):运行时需创建**信号管道**,沙箱 workspace-write 模式会阻止(`couldn't create signal pipe` 错误)。
- **必须提权运行**(danger-full-access),且通过 `cmd /c` 或批处理调用,输出重定向到文件(直接管道捕获也会触发 cygwin 管道限制)。
- 已验证:提权下 thdat/thanm/thecl/thstd/thmsg 全部正常(exit 0),th18/th185/th19/th20 拆包+转换完成。
- **工具用法差异**(实测):
  - thdat: `thdat -x <ver> <in.dat>`(输出到 CWD)
  - thanm: `thanm -x <ver> <in.anm>`(输出到 CWD 子目录, 按 anm 内路径层级)
  - thecl: `thecl -d <ver> <in.ecl> <out.ecl.txt>`(dump)
  - thstd: `thstd -d <ver> <in.std> <out.std.txt>`(dump)
  - thmsg: `thmsg -d <ver> <in.msg> <out.txt>`(dump)
- 版本支持: 6/7/8/9/95/10/11/12/125/128/13/14/143/15/16/165/17/**18/185/19/20**

## 〇·二、tf 侧工具实测结论(pushfiles 作业 2026-08-27)

### SWR 引擎(th075/th105/th123)
- **thtk thdat v12**:`thdat -x 105|123` 拆包 th105a/b/c、th123a/b/c;`-x 6` 拆 kouma。
- **th105 日文文件名问题**:thdat 在 GBK 系统把 SJIS 文件名解成**乱码**(如 `余.cv2`→`梋.cv2`)。tf_tree_data 的 key 是修复名,但新拆包得乱码名 → 需 `cp932→gbk` 回退匹配(已验证)。
- **th105c.dat(补丁后)**:当前源 13MB(旧记录 60MB 汉化包已变),拆 247 文件;touhouSE 转换(cv2→png 198 含 8bpp, cv3→wav 6);**touhouSE 输出无 data/ 前缀**(直接 `card/...`)。
- **touhouSE 用法**:`touhouSE.exe -c <dat>` 输出到 exe 旁 `data\`;需复制到沙箱工作目录。支持 8bpp cv2(需 .pal)。
- **th075**:brightmoon 拆包(Suica);内层 dat(background/BG*.dat→png、wave/se*.dat→wav)产物在 `_converted/th075/`(cpath 无 `_converted/` 前缀, 与 th105 不同!)→ locate() 需兼容两种前缀。
- **th075bgm.dat**:brightmoon 拆出 `wave/`(34 wav),无转换(原样保留)。

### TFPK 引擎(th135/th145/th155/th175)
- **th135arc-alt**:`-x <pak>` 输出到 **CWD 下 <stem>/ 目录**;⚠️ **输出跟随 pak 所在目录(无视 CWD)**,曾污染源目录 `tf/th135/th135b/` → **必须复制 pak 到沙箱工作区再解**。
- **th145arc**:`/x <pak>`;**从 CWD 读 fileslist.txt 做路径映射**,缺它则全输出 `unk_*` 名(data/ 丢失)→ 复制 `tools/135tk/135tk/fileslist.txt` 到沙箱 CWD。
- **th175arc**:`-x <pak> <outdir>`(可指定输出目录,单横线);从 CWD 读 fileslist.js;输出完整路径。
- **转换产物来源**:th135/145/155 的 bmp/png 是 TFBM 伪装,产物在 `_converted/{game}/`(cpath 带 `_converted/` 前缀);nut 在 `_converted/nut_dump/{game}/`。TFPK 作统一用 `_converted/` 作 CONV_ROOT。
- **unk_*.png(TFBM 伪装)**:产物在 `_converted/{game}/unk_png/`,转换目录为源文件名(unk_xxx.png/)。
- **th135 mob_position/*.dat**:8 个二拆 → txt(在 `_converted/mob_position_txt/`)。

### 通用注意
- **转换产物 cpath 两种格式**(实测):th105/th123 = `_converted/th105/...`(带前缀);th075 = `th075/background/...`(无前缀)→ locate() 依次试 `_converted/` 根和 `release/tf/` 根。
- **pushfiles 规则执行**:转换(先 b:删源建目录放产物)、二拆(后 a:删 dat 建目录放产物),全部通过 pushfiles_th*.py 执行器完成。

## 三、作业目录约定

- 输出根: `pushfiles\`(release 不写入)
- 结构: `pushfiles\<作品代号>\<源档案名>\` → 一拆产物
- 二拆/转换: 同源文件名字建子文件夹(如 `msg1.dat\msg1.txt`)
- thbgm.dat: 仅原始切分 `raw\*.wav`(本轮不做 render)
