# STRUCTURE — th20(錦上京)STD 结构分析(降级)

- 任务:t94 | 执行:extractor-c2 | 日期:2026-08-24
- 背景:`thstd -d 20` 实测返回 "version 20 is unsupported"(rc=1,graceful);10 个 .std(st01–st07 ± 4a/4b/4c/4d)
  无法工具转换,按降级口径产出结构分析。
- 样例:st01.std(2,232B)、st04a.std(8,004B,路线分歧)、st07.std(2,064B)
- hex 侧车:本目录 `*.std.hex`(512B)

## 1. 文件头(实测)

```
偏移      大小    内容                        st01.std        st04a.std       st07.std
0x00      u16     疑似段数                    3               0x0E(14)        4
0x02      u16     ?                           0x10            0x94            0x10
0x04      u32     疑似头/数据尺寸?             0x02F8(760)     0x13D0(5072)    0x0330(816)
0x08      u32     疑似总尺寸?                  0x0488(1160)    0x16F0(5872)    0x0450(1104)
0x0C      u32     恒 0
0x10      char[16] 舞台布局 ANM 引用          "st01wl.anm"    "st04wla.anm"   "st07wl.anm"
0x20..0x8F        填充/预留
0x90      u32[]   记录偏移表                 st01: 0x9C,0xEC,0x21C…(3 条)
                                            st04a: 0xC8,0x24C,0x360,0x4E4…(14 条,对应 0x00 段数)
                                            st07: 0xA0,0x17C,0x258,0x2C4…(4 条)
0xA0+     记录体   f32 浮点参数 + 记录头      见下
```

## 2. 记录体(实测)

- st01.std 0xA0 起:多个 (f32,f32,f32) 组(如 `0x4396=300.0, 0x4480=1024.0, 0x4400=512.0`——屏幕尺寸级数值),
  记录头含 u32 类型/长度字段;
- st04a.std 段数 14、偏移表 14 条,与 th08 时代 std 的「段数 + 偏移表」结构同族;
- 各 std 引用对应舞台的 **wl.anm**(如 st01wl.anm = 第 1 面舞台背景布局动画)。

## 3. 结论

- th20 std = 头(u16 段数 + u32 尺寸 + `stXXwl.anm` 舞台引用)+ 记录偏移表 + f32 记录体;
- 结构同族可解析(引用表/偏移表/浮点参数可识别),但记录体字段语义需新版本工具;
- **建议**:等 thtk 更新;或按偏移表自行 dump 记录头(类型+长度)做进一步逆向。
